   - Call existing `transferOrQueue({ amountCents, destination, payoutsEnabled, transferGroup: campaign_id })`.

   - Mark a campaign `paid` if it is not already paid.
   - Call Stripe if `payouts_enabled` is false (reuse `canReceiveConnectTransfer`).
