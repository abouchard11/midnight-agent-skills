# YC / Garry Tan Personal AGI practices (mid-2026)

Signal from the last two weeks of founder talk, plus the GStack launch:

- **Personal AGI:** agents on your infrastructure that compound your knowledge. Not a chatbot. A stack.
- **Smaller teams than ever:** one person plus agents. Tan's public claim is an 810× logical-line pace vs 2013, measured across his repos.
- **Markdown is code.** A well-written skill file is an employee. Version it.
- **Skill-maxxing:** turn every recurring procedure into a loadable skill with a trigger and a verifier.
- **GStack:** virtual org as slash commands (CEO, EM, designer, QA, security, release, retro).
- **GBrain:** personal memory over markdown — the missing companion to a graph skill. Use `companions/gbrain/`. The model does not own `remember`.

When building agent systems, default to producing reusable `SKILL.md` files or graph definitions that can be checked into the repo.

Do not copy GStack's org chart. Copy the discipline: every recurring job becomes a named, loadable procedure with a stop condition.
