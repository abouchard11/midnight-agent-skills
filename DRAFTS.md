# Skill publication notes

This suite includes four additional workflow skills in draft lifecycle: `ablation`, `compendium-research`, `lead-gen-pipeline`, and `voice-character-engine`. They are instructions for scoped analysis and design, not executable services or evidence that any external integration is deployed. `voice-character-engine` is character design/evaluation; it is a separate domain from SEO skills.

Two checkpointed candidates are intentionally not published as skills here:

- **`skill-ify`** overlaps the existing skill-creation guidance and should use the repository's current skill creator rather than create a competing workflow.
- **`vault-sync`** contains a historical, deployment-specific operational recipe. It needs a fresh runbook review and environment-specific authorization before any operational instructions are published.
